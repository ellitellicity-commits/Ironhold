Two Paths, One Portfolio

Primary: Farm Agricultural Data Project  ·  Backup: L.R. TactiCam (Sports CV)  ·  Trip window: Aug 5–28
PLAN A — Farm Agricultural Data Project (Primary)
A Passion Project rooted in family legacy, layered with real Impact — not a rigid corporate tool. Built around a flexible ~1.5–2 week on-site window.
1Scope & Brainstorm
  • What questions matter to the family / farm itself?
  • Candidate themes: soil, crop health, livestock, irrigation, yield
  • Narrow to 1–2 focal themes before arriving
2On-Site Collection
  • Photos / video (phone, drone if available)
  • Sensor logs or manual field notes
  • GPS-tagged field walks
  • Interviews with family members
3Structure & Clean
  • Organize by field and date
  • Label imagery (crop type, health, pests)
  • Build a simple schema (CSV / JSON)
4Analysis / Model
  • Trend charts over time
  • Basic CV crop/health classification, if imagery is rich enough
  • Otherwise: solid descriptive stats
↓
5Narrative Layer
  • Family legacy framing
  • Before/after, season-over-season comparisons
  • Impact angle: sustainability, small-farm resilience
6Portfolio Deliverable
  • Interactive dashboard / story-driven web app
  • Visual reports: maps, charts, photo timelines
  • Write-up on process and why it matters
Feasibility Checkpoints (given flexible farm window)
  • ≥ ~1.5 weeks + rich data → run full Plan A, including CV analysis
  • Short window / sparse data → scale down to the narrative/descriptive version — still Plan A, lighter model
  • Collection falls through entirely (access, weather, timing) → pivot fully to Plan B
Decision point: reassessed live once actual farm dates are locked in during the trip, before Aug 28. Either path keeps the "personal inspiration + impact" identity — not just a technical exercise.
fallback if on-farm data collection proves infeasible
PLAN B — L.R. TactiCam (Backup / Sequel Concept)
Sports Computer Vision · direct sequel to the World Cup app · tracks soccer players & the field to generate tactical overlays.
1Concept & Scope
  • Which tactical questions: formations, pressing, spacing, heatmaps?
  • Reuse the World Cup app's visual language and branding
2Source Footage
  • Broadcast clips / public match footage
  • Fixed tactical-cam angle ideal for homography
  • Start with a handful of sample clips
3Detect & Track
  • Player/ball detection (pretrained CV model)
  • Multi-object tracking with persistent IDs
  • Team classification via jersey color
4Field Registration
  • Detect pitch lines & corners
  • Homography → warp to top-down tactical view
  • Map player coordinates onto a standardized pitch
↓
5Tactical Overlays
  • Formation shapes
  • Heatmaps & coverage zones
  • Pressing triggers, spacing lines
  • Speed / distance metrics
6Portfolio Deliverable
  • Interactive replay app — scrub through a match
  • Exportable tactical clips
  • "Sequel" framing tying it back to the World Cup app
