Backend / Game Engine

Mostly you, hardcoded, ask for help when stuck
Tower (abstract)
Range, damage, fire rate, targeting rule. Subclassed per tower type.
extended by → DartTower, CannonTower, SlowTower
Enemy (abstract)
Health, speed, path position, reward on death. Subclassed per enemy type.
extended by → BasicEnemy, FastEnemy, TankEnemy
Attackable / Targetable (interface)
Lets towers query and hit any enemy without caring which subclass it is.
Grid / Path
Holds the map layout, valid tower spots, and the enemy route.
Wave / WaveManager
Spawns enemies over time, escalates difficulty wave to wave.
GameState
Currency, lives, current wave, win/loss condition.
ties everything above together each game tick

Style direction, borrowing from both references

From Bloons

  • Bright, saturated colors, high contrast against the path
  • Chunky, rounded fonts for HUD text
  • Playful pop feedback on hits and kills
  • Towers read instantly by silhouette, not just color

From Tower Defense Simulator

  • Clear grid logic, obvious valid placement spots
  • Clean top-down HUD: currency, lives, wave counter always visible
  • Readable range indicators when placing a tower
  • Escalating wave structure with a visible "next wave" cue
