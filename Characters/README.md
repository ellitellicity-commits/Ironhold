# Characters

Design notes for towers, enemies, and the hero — stats, behavior, sprite
references. Not code (that's Tower/Enemy classes under src/main/java).

Default v1 roster:
- Towers: Archer Post, Ballista, Stake Wall
- Enemies: Raider, Skirmisher, Brute
- Hero: directly controllable, basic attack, one ability (later)

## Art collaborator
